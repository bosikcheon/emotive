Firebase 연결 마무리

프로젝트: emotive-71134
사용 서비스: Firebase Authentication + Realtime Database

  1. Authentication에서 이메일/비밀번호 로그인을 활성화합니다.
  2. Realtime Database에서 생성한 데이터베이스를 선택합니다. 연결 URL: https://emotive-71134-default-rtdb.asia-southeast1.firebasedatabase.app
  3. Realtime Database의 규칙 탭에 아래 규칙 전체를 붙여넣고 게시합니다.
  4. 홈페이지에서 본인의 계정을 가입합니다. 모든 가입자는 일반 회원입니다.
  5. Realtime Database → users → 가입한 계정 UID 노드 → role 값을 member에서 admin으로 변경합니다. 본인이 Firebase 콘솔에서 지정해야 하며 홈페이지에서는 변경할 수 없습니다.
  6. 홈페이지를 새로고침하고 관리자 스튜디오에 들어갑니다. ‘예시 8종 등록’을 누르면 기획 콘셉트가 준비 중 상태로 등록됩니다. 이미 존재하는 같은 ID의 작품은 덮어쓰지 않습니다.

실행 방법

파일을 더블클릭하지 말고 PowerShell에서 아래 명령으로 실행하세요.

cd "P:\AI\바이브코딩\12_EMOTIVE\EMOTIVE"
python -m http.server 4175

http://localhost:4175/에서 확인합니다. Auth의 승인된 도메인이 필요한 기능을 추가하면 localhost와 배포 도메인도 확인하세요.

Realtime Database 보안 규칙

확인할 기능
  • 회원가입 후 Authentication에 계정, Realtime Database users에 프로필 생성
  • 로그아웃 및 재로그인, 새로고침 후 로그인 유지
  • 관리자 작품 등록·승인·비공개 처리
  • 일반 회원의 작품 수정·다른 회원 정보 접근 차단
  • 팬 메시지 작성, 작성자 삭제, 관리자 답변
  • 계정별 찜·보관함 분리, 다른 기기에서 재로그인 후 데이터 조회
기존 localStorage 데모 데이터 및 Firestore 데이터는 자동으로 이동되지 않습니다. 기존 Firebase Authentication 계정은 그대로 로그인할 수 있습니다. Realtime Database 프로필이 없으면 일반 회원 프로필이 생성됩니다. 홈페이지의 비밀번호 관리와 첫 가입자 관리자 방식은 제거되었습니다. 회원 관리 화면은 Realtime Database에 등록된 프로필 목록이며 Auth 계정 삭제·비활성화 기능은 제공하지 않습니다.
이메일 로그인 활성화 여부, Realtime Database 생성 및 규칙 게시 여부는 프로젝트 콘솔에서 확인해야 합니다. SDK 초기화만으로 이 설정들이 생성되지 않습니다.
